# Ejer_Arreglos

Lo que realiza el programa es generar una tabla bidimensional con filas y columnas siendo las filas los meses y las columnas los departamentos, se pueden agregar departamentos y los precios de los mismo departamentos, los metodos que existen son 7 y solo 6 son los del menu que aparecen al ejcutar el codigo 

lo metodos son los sig:

def generar_ventas(): Este genera automaticamente costos de las ventas de cada departamento, vaya que rellena la tabla con distintos precios por si no lo haces manualmente
def insertar_venta(mes, departamento, cantidad): Esta es la manera manual de meter los datos de la ventas
def buscar_venta(mes, departamento): Este es como el buscador de alguna venta en especifico
def eliminar_venta(mes, departamento): Eliminador de ventas 
def mostrar_ventas():Muestra la tabla con las ventas ya registradas
def mostrar_meses(): Crea el orden d elos meses 
def mostrar_departamentos(): Crea los departamentos
